# Portfolio website

Personal portfolio of **Ziad Elhussein**, AI & machine learning engineer: [ziadelh.github.io](https://ziadelh.github.io/).

Plain HTML, CSS and JavaScript with no build step, hosted on GitHub Pages. It has a Pawlytics case study, a filterable and searchable grid of all projects, light and dark themes, and a layout that works from phone to desktop.

```
index.html          page structure
css/style.css       design tokens, layout, light/dark themes
js/main.js          project grid, filters, theme switch, scroll effects
data/projects.js    every project on the site (one entry each)
img/projects/       800x500 thumbnails
assets/             downloadable CV
```

To run it locally, open `index.html` in a browser, or serve the folder with `python -m http.server`.
